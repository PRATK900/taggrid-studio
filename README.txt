TagGrid Studio — installable web app package

Files included: index.html, manifest.json, sw.js, icon-192.png, icon-512.png.

Deploy all five files to the same folder on an HTTPS static host (for example GitHub Pages or Netlify). Do not open index.html directly from local file storage.

On Android: open the deployed HTTPS site in Chrome, open the menu, and choose Install app if offered. The site is configured for standalone display.

Note: this package creates an installable PWA, not a native Android APK.
