Install TagGrid Studio

1. Offline Standalone App (Immediate)
Keep this TagGrid-Studio.html file on your phone or PC. Double-click or tap it anytime to open and generate 300/600 DPI price tag PDFs offline.
2. Install on Android / iOS Home Screen
Open this file in Chrome (Android) or Safari (iOS), tap the browser menu (⋮ or Share), and tap "Add to Home Screen".
3. Install as Desktop App (Chrome / Edge)
Extract TagGrid-Studio-PWA.zip and host or open via local server (or Netlify Drop) and click the Install App icon in the address bar.
